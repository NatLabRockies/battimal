# battimal: **Batt**ery **I**ntelligence and **Ma**chine **L**earning

 `battimal`, short for **Batt**ery **I**ntelligence and **Ma**chine **L**earning, is a software library that connects battery data processing, feature extraction, and model feature/target formatting into one package.
